    Error Codes

    Every code of the MTHDS core error registry has a page here, at the URL a problem's type names: https://mthds.ai/errors/<code>. Each page says what its code means, who must act and what to do, and gives the code's steps, parameters and templates. The Error Registry page describes the registry itself, and the HTTP Runner Protocol how a problem document carries a code.

    These pages are generated from the registry's data, which is published with every release of the standard as mthds-error-registry.json. This is version 8.0.0 of the registry.

    Extension prefixes

    A code that is not a core code starts with a registered prefix, and its page is published by the prefix's owner, under the base URL the prefix is registered with.

    Prefix Owner Base URL
    pipelex. Pipelex https://docs.pipelex.com/errors

    request.blobs_missing The runner does not hold some files sent by hash input no 422
